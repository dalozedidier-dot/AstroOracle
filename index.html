AstroOracle

Active learning oracle for astronomical anomaly triage. This page is static (GitHub Pages friendly). For the live demo, run the FastAPI server locally or deploy it on a small PaaS.

Run locally
pip install -e ".[dev,api,plotly,graph]"
astrooracle serve
# open http://127.0.0.1:8000/
GitHub PyPI
What's inside
  • FastAPI landing page + dashboard
  • SkyView cutouts (or offline synthetic mode)
  • Plotly 3D preview
  • Graph anomaly context + explainability prompts

Note about GitHub Pages

GitHub Pages serves static files only. The interactive landing page lives in the FastAPI app (route /). To publish a public live demo, deploy the API on Render/Fly.io/Railway and point users to that URL.
